# prd2zentao 前期操作手册

> 用 Claude 把 PRD 同步到禅道前,你需要先做的准备。一次性配置做一遍即可,之后每次同步只需做"每次同步前"那几步。

---

## 一、一次性配置(只做一遍)

### 1. 安装 Claude for Chrome 扩展

- Chrome 应用商店搜索 **"Claude"**,认准开发者是 **Anthropic**(官方),安装。
- 商店直链:`https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn`
- 前提:有 Claude 付费订阅。
- 注意:只支持 Chrome,不支持其他 Chromium 浏览器和手机。

### 2. 登录并连接

- 点浏览器右上角的 Claude 扩展图标,用你的 **Claude 账号**登录。
- 打开侧边栏,按提示授权 / 开启连接,允许它被 Cowork 控制。
- 连好后,Claude 这边能检测到你的浏览器(显示为 "Browser 1" 之类)。

---

## 二、每次同步前(每次都要做)

### 1. 打开禅道并登录

- 在**同一个 Chrome 浏览器**里打开禅道,用**你的禅道账号**登录好。
- 关于账号:禅道账号和 Claude 账号是两回事,**不需要一致、也不需要互相授权**。Claude 是借用你已登录的禅道会话来操作,全程不碰你的禅道密码。
- 保持这个标签页处于登录态(API 创建需求靠的就是这个登录会话)。

### 2. 确认要同步到哪个产品(关键)

- **不同产品在禅道里是不同目录,搞错产品需求会散落、要逐条删。**
- 怎么拿 productID:打开目标产品的需求列表页,看地址栏 URL 里的 `productID=XX`。
  - 例:`http://你的禅道域名/index.php?m=product&f=browse&productID=75` → productID 是 **75**。
- 打通链路/试跑请先用**测试产品**;正式同步时务必再次确认是**正式产品**的 productID。

### 3. 准备好 PRD

- PRD 第四章「产品范围」要已经稳定(需求就从这一章拆)。
- 告诉 Claude:PRD 文件在哪、同步到哪个产品(productID)。

---

## 三、开跑时,跟 Claude 怎么说

一句话把关键信息给齐,例如:

> "把 `02-网管/产品设计/V1.x.x-配置核查` 的 PRD 同步到禅道,产品是『禅道功能验证』(productID 75),先建模块再批量建需求。"

Claude 会:拆需求清单 → 跟你确认粒度/优先级/来源 → 建二级模块 → 先建 1 条试点验证 → 批量建完 → 截图给你核对。

---

## 四、几个要你拍板的点(Claude 会问)

- **需求粒度**:一篇 PRD 拆成几条,Claude 给建议你确认。
- **优先级**:默认都是 ①,哪几条调成 ②/③ 由你定。
- **来源**:禅道必填字段,但具体归类(客户/项目团队/行业规范…)要**你或产品经理**确认,Claude 不擅自拍板,默认用"客户沟通时提出需求"。
- **删除类操作**:出于安全,删模块/删需求这类操作 Claude 不替你做,会让你自己点。

---

## 五、常见问题

- **"扩展连不上 / 检测为空"**:确认扩展已登录 Claude 账号且开了连接;重开侧边栏再试。
- **"返回 HTML 登录页"**:禅道掉登录了,重新登录禅道再让 Claude 重试。
- **"评审人不能为空"**:这是禅道开了需求评审。Claude 会自动带"不需要评审"(needNotReview);若你们流程必须评审,告诉 Claude 评审人是谁。
- **建错产品了**:停下来,确认正确 productID,把建错的需求删掉重来。所以**开跑前一定确认产品**。
